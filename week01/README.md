# Project 1 EDA Notebook

## Overview
This project contains an exploratory data analysis of the Titanic passenger dataset. The goal is to inspect the quality of the data, understand the target variable, and document the likely modeling risks without performing imputation during the EDA stage.

## Files
- project1_eda.ipynb: notebook with the analysis and plots
- FINDINGS.md: written findings document with structured notes
- titanic_dataset.csv: dataset used for the analysis

## Source
The data used here is the Titanic passenger dataset that is commonly used for EDA and introductory modeling work. It was included in the assignment materials for this course and is used here for educational analysis.

## Licence
This project is being used for coursework and educational analysis under the assignment context. The dataset should not be redistributed beyond the course environment without checking the original licensing conditions.

## How to run
1. Open the project folder.
2. Start the Python environment for the project.
3. Open the notebook in VS Code.
4. Restart the kernel if needed.
5. Run all cells from top to bottom.
